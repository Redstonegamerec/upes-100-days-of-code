# UPES 100 Days of Code - Complete C Solutions

This project contains Day 1 through Day 100.

- Day 1-50: two programs per day.
- Day 51-100: one program per day.
- C code is formatted across multiple lines for easier reading in VS Code.

Open this folder in VS Code using File > Open Folder.

## History

Imported on November 23, 2026. Commit dates were assigned retrospectively to organize these existing solutions over 100 consecutive days (August 16–November 23, 2026); they do not record the actual dates the programs were written.
